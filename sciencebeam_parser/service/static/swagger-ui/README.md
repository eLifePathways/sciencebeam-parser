# Swagger UI

`swagger-ui-bundle.js`, `swagger-ui.css` and `favicon-32x32.png` are taken
unchanged from [swagger-ui-dist](https://www.npmjs.com/package/swagger-ui-dist)
**5.34.1**, which is Apache-2.0 licensed (see `LICENSE`).

They are served from here so that the API documentation page works wherever the
service does, including with no network access. Updating them means replacing
the three files from the same version of that package and nothing else.
